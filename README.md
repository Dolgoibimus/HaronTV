# ХаронТВ (HaronTV)

Двухпанельный файловый менеджер для Android TV и приставок. Всё управление — пультом: сети, облака, торренты, архивы, терминал.

- **Автор:** Виктор Уткин
- **Имя пакета:** `com.vamp.haron.tv`
- **Требуется:** Android 9.0 и выше
- **Скачать:** [Releases](https://github.com/Dolgoibimus/HaronTV/releases/latest)
- **Тема на 4PDA:** https://4pda.to/forum/index.php?showtopic=1129655
- **Версия для телефона — Харон:** https://4pda.to/forum/index.php?showtopic=1119412
- **Сайт:** https://vampilenna.online/
- **Связь:** vampilenna@gmail.com

## Какую сборку выбрать

| Файл | Что внутри |
|------|-----------|
| `HaronTV-<версия>-full-…apk` (87–99 МБ) | Всё встроено: VLC-плеер со всеми кодеками, PDF-читалка с поиском, распознавание текста и объектов на фото, FFmpeg, торрент-стриминг во встроенный плеер |
| `HaronTV-<версия>-mini-…apk` (около 31 МБ) | Все функции проводника на месте; видео и аудио открываются во внешнем плеере (VLC, MX Player и т.д.), PDF — читалкой на системном движке Android |

`arm64-v8a` — для 64-битных приставок, `armeabi-v7a` — для 32-битных (большинство недорогих ТВ-боксов). Не знаете, какая у вас, — берите `armeabi-v7a`, она запускается на обеих.

## English

HaronTV is a dual-pane file manager for Android TV and set-top boxes, fully controlled with a remote: network shares, cloud storage, torrents, archives, terminal.

- **Author:** Viktor Utkin
- **Package name:** `com.vamp.haron.tv`
- **Requires:** Android 9.0+
- **Download:** [Releases](https://github.com/Dolgoibimus/HaronTV/releases/latest)

Builds: **full** (built-in VLC player, PDF reader, OCR, FFmpeg) and **mini** (lightweight, uses an external video player). `arm64-v8a` for 64-bit devices, `armeabi-v7a` for 32-bit ones (runs on both).

This repository hosts release builds only; the source code is not published.
